# Event-registration-portals-


full-stack Event Registration Portal developed using HTML, CSS, JavaScript, Node.js, Express.js, and MongoDB. This application allows users to register for events and stores registration details in a MongoDB database.
Features
User-friendly event registration form
Store participant details in MongoDB
View all registrations through API
Responsive frontend design
RESTful backend API
Tech Stack
Frontend
HTML5
CSS3
JavaScript
Backend
Node.js
Express.js
Database
MongoDB
